# JD 知识点与实战地图

此项目覆盖可通过代码学习的技能，不把学历、工作年限、团队协作经历或生产经验等同于演示代码。

| JD 能力 | 本工程落点 | 练习 / 验收 |
| --- | --- | --- |
| 全链路架构 / 全栈交付 | Vue3 + TS + FastAPI + SQLite + SSE | 从表单追到请求 schema、队列、工具、持久化和 UI 结果 |
| AgentLoop / ReAct | runtime.py 有界动作执行与 observation 事件 | 修改 Mock 路由，加入工具；设置预算不足并观察失败 |
| Plan-and-Execute | plan 模式显示预定动作后执行 | 将计划扩展为 DAG，增加依赖校验和失败补偿；计划模式遍历预定动作，ReAct 每步将 observation 回传 Mock 决策器 |
| Context Engineering | 当前请求优先、历史裁剪、记忆预算、证据块上限 | 构造长历史验证 current 不丢失；接真实 tokenizer 后比较字符预算 |
| 记忆系统 | localStorage 短期历史 + SQLite 显式长期事实 | 两个 session 写入不同偏好，验证隔离和删除 |

| Skills | 可阅读的故障排查 SKILL.md 与 API 注册发现 | 新增一个指南目录并在 UI 查看；后续做受控 Skill 选择器 |

| 安全 | Pydantic、参数化 SQL、能力白名单、非 root 容器配置 | 自动化恶意表达式测试；生产补充鉴权与租户授权 |

| 自动化测试 / QA | pytest、TS 类型、ESLint、构建、CI | npm run check；每项关键行为加入正向与失败测试 |

| 前沿技术转化 | Model / 工具 / 检索解耦、基线候选评估 | 对新方案先定义目标与失败边界，再用相同数据比较 |

## 建议学习顺序

1. Python API 与 Vue 数据流：完成聊天与 SSE 阅读。
2. 工具与安全：从 calculator 入手理解 schema、权限边界、失败处理。
3. RAG 与记忆：检索指标和上下文预算比单纯拼 prompt 更重要。
4. 编排与可靠性：对照 Mock 理解范式，再接真实模型、循环决策与工具结果回灌。
5. 评测与可观测性：每个新能力需要可验证结果和可定位的失败记录。
6. 生产演进：先实现身份与租户、分布式任务语义，再扩实例和资源。

## AI 辅助开发工作流

将需求写成可验收场景 → 提供相关模块与约束 → 小范围生成/修改代码 → 人工检查权限、副作用和异常路径 → 执行类型/测试/构建 → 用真实 UI 验收 → 将事故样本加入回归。禁止向模型提交生产密钥或客户敏感数据；模型生成的依赖版本与 API 用法必须通过安装、编译和测试验证。
